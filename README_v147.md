# v147 — современный картографический интерфейс и стабилизация управления слоями

## Что изменено

- Левая панель получила новую компактную структуру в стилистике современного ГИС-веб-приложения.
- Слои собраны в три группы: базовая карта, точки и подписи, аналитические оверлеи.
- Добавлены поиск по слоям, возврат к состоянию по умолчанию и быстрый базовый пресет.
- Состояние основных переключателей сохраняется в `localStorage` и восстанавливается при следующем запуске.
- Добавлен финальный декларативный диспетчер видимости, который синхронизирует чекбоксы с Leaflet-слоями после старых патчей.
- Отдельно стабилизированы гидрография, административный слой, контур АТД-1, железные дороги, круги населения, центры, подписи, топологический граф и линейные слои границ.
- Подписи АТЕ теперь можно включать независимо от полигонов.
- Реализовано динамическое прореживание подписей:
  - по масштабу;
  - по площади экранного контура АТЕ;
  - по приоритету населения и площади;
  - по коллизиям с уже размещёнными подписями;
  - совместно для подписей полигонов и городов/центров.
- Добавлены настройки плотности, минимального масштаба и отображения значения активного показателя.
- В аналитических режимах подпись может показывать население, плотность, доли, железнодорожные и топологические показатели.
- Добавлена верхняя строка статуса карты: активные слои, масштаб и координаты курсора.
- Обновлены панели, переключатели, временная шкала, кнопки, подсказки и адаптивная компоновка.

## Совместимость

Версия не переписывает накопленную картографическую логику. Новый код добавлен финальным слоем поверх v146, поэтому существующие расчёты, режим экспорта, временные срезы и аналитические оверлеи сохранены.

## Проверки

- `node --check app.js` — успешно.
- JSON-манифест читается и соответствует версии `v147`.
- Все статические кнопки, select и input левой панели имеют обработчики.
- Проверены группировка слоёв, поиск, базовый пресет и рендер динамических подписей в браузерном тестовом стенде.
