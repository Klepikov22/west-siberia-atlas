# Основные этапы проекта

Краткий указатель к важным изменениям. Полные послойные правки сохранены в истории Git, расчётных скриптах и диагностических файлах `docs/diagnostics/v*`.

- **v154:** восстановлено отображение символов населения в штатном SVG-слое Leaflet при сохранении наведения и выбора объекта.
- **v153:** на базе очищенного интерфейса добавлена интерактивность кругов населения, непрерывная ось временной шкалы, начальное сворачивание фильтров АТЕ и более компактное размещение панелей. Одинаковая сводка скрыта слева, сырые атрибуты раскрываются в карточке; управление экспортом перемещено ниже легенды. Геометрия выборки выделена в `atlas-geometry.js`; добавлены [ARCHITECTURE.md](ARCHITECTURE.md) и проверка административных GeoJSON.
- **Чистка и выборка:** движок выборки переписан (`selection-sketch.js` + блок в `map-runtime.js`): у курсора стрелка вместо «руки», рамка и полигон видны при рисовании, полигон замыкается кликом по первой вершине. Из интерфейса убраны оболочка, выбор стилей/темы, ползунки подписей и символов, диаграммы-настройки; скрипты перенесены в `pipeline/`, отчёты — в `docs/reports` и `docs/diagnostics`, устаревшие версии скриптов удалены.
- **v151:** инструменты курсора, рамки, полигона и выбора области АТД-1; явные действия над выборкой, критерий полного включения; корневой README и тесты. Документация переработана, ранние сборщики connectivity удалены из рабочего дерева, проверка структуры вынесена в `scripts/atlas_healthcheck.py`.
- **v149–150:** единый картографический runtime для интерактивности, подписей и видимости слоёв; оформление картографических подписей.
- **v139–148:** стабилизация загрузки, управления слоями, экспорта, трендов и стилей для защиты ВКР. Накопленные обёртки в `app.js` остаются техническим долгом.
- **v124–138:** природная приуроченность и преемственность границ, геодезический пересчёт ЖД, компонентная модель потенциальной связности.
- **v104–123:** пересчёт охвата сводной статистики, уточнение населения ранних слоёв и 1947 г., прокси-возраста районов и исторических названий.
- **v83–98:** стандартизация ранних слоёв и специальных территорий, геометрическое соседство и топологический граф.
- **v53–82:** разделение городского и несельского населения, новые срезы 1947 и 1964 гг., нормализация атрибутов и геометрий.

Для интерпретации действующих полей и методических ограничений читайте [METHODS.md](METHODS.md). Версионные `README_v*.md` удалены из рабочего дерева; прежние версии доступны в истории Git до чистки документации.
