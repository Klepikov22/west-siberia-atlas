# Исторический веб-атлас Западной Сибири

Интерактивные временные срезы административно-территориального деления Западной Сибири, населения, транспорта и пространственных связей. Проект создан для ВКР и работает как статический сайт: серверная часть и сборка не требуются.

## Запуск

Из корня репозитория запустите локальный HTTP-сервер:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000/`. В Windows вместо `python3` обычно используется `py`. Открытие `index.html` напрямую через `file://` не подходит, поскольку браузер блокирует загрузку GeoJSON через `fetch`. Leaflet и html2canvas подключаются из CDN (нужен интернет).

## Работа с выборкой

| Инструмент | Действие | Курсор |
| --- | --- | --- |
| Курсор | Клик по АТЕ показывает атрибуты и выделяет объект. Зажать и тянуть — двигать карту. | стрелка; над объектом — указатель; «рука» только во время перетаскивания |
| Рамка | Зажать кнопку и протянуть прямоугольник; область видна под курсором. | перекрестие |
| Полигон | Кликами ставить вершины (линия тянется за курсором). Завершить: клик по первой вершине, двойной клик, Enter или правая кнопка. Backspace — убрать вершину, Esc — отмена. | перекрестие |
| Область АТД-1 | Клик по АТЕ выбирает все видимые объекты с тем же `admin_parent`. | указатель |

«Действие» — новая выборка / добавить / убрать (Shift временно добавляет, Alt убирает). Для рамки и полигона критерий: «Пересекает контур» или «Полностью внутри».

## Структура репозитория

```
index.html           разметка интерфейса
style.css            оформление
app.js               данные, слои, показатели, экспорт, фильтры (исторически большой файл)
map-runtime.js       отрисовка слоёв, подписи, события карты, движок выборки
selection-sketch.js  эскиз рамки и полигона (отдельный SVG-слой поверх карты)
data/                GeoJSON и таблицы; data/manifest.json — перечень срезов
pipeline/            скрипты подготовки данных (запускать из корня репозитория)
scripts/             проверка структуры (atlas_healthcheck.py)
tests/               тесты логики выборки (node --test)
docs/                METHODS.md, CHANGELOG.md, reports/ и diagnostics/ — отчёты расчётов
```

Как адаптировать под другую территорию (например, Турцию): подготовьте GeoJSON по образцу `data/admin/admin_<год>.geojson`, перечислите срезы в `data/manifest.json`, обновите центр и масштаб карты в `app.js`, затем запустите проверки ниже. Скрипты `pipeline/recalc_v*.py` — этапы обработки именно этих данных, их достаточно читать как примеры методики; перезаписывают файлы в `data/`.

## Проверка изменений

```bash
node --test tests/*.test.js
python3 scripts/atlas_healthcheck.py
```

## Данные и источники

Основные методические оговорки сведены в [METHODS.md](docs/METHODS.md), а история ключевых изменений в [CHANGELOG.md](docs/CHANGELOG.md). Подробные операции с данными доступны в диагностических CSV/JSON `docs/`, исходных расчётных скриптах и истории Git. Перед повторным использованием набора проверьте применимость конкретного временного среза: реконструкции не образуют однородный ряд современных АТЕ.
