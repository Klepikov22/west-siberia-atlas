# Исторический веб-атлас Западной Сибири

Интерактивные временные срезы административно-территориального деления Западной Сибири, населения, транспорта и пространственных связей. Проект создан для ВКР и работает как статический сайт: серверная часть и сборка не требуются.

## Запуск

Из корня репозитория запустите локальный HTTP-сервер:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000/`. В Windows вместо `python3` обычно используется `py`. Открытие `index.html` напрямую через `file://` не подходит, поскольку браузер блокирует загрузку GeoJSON через `fetch`. Leaflet и html2canvas подключаются из CDN (нужен интернет).

## Работа с выборкой

| Инструмент | Действие | Курсор |
| --- | --- | --- |
| Курсор | Клик по АТЕ показывает атрибуты и выделяет объект. Зажать и тянуть — двигать карту. | стрелка; над объектом — указатель; «рука» только во время перетаскивания |
| Рамка | Зажать кнопку и протянуть прямоугольник; область видна под курсором. | перекрестие |
| Полигон | Кликами ставить вершины (линия тянется за курсором). Завершить: клик по первой вершине, двойной клик, Enter или правая кнопка. Backspace — убрать вершину, Esc — отмена. | перекрестие |
| Область АТД-1 | Клик по АТЕ выбирает все видимые объекты с тем же `admin_parent`. | указатель |

«Действие» — новая выборка / добавить / убрать (Shift временно добавляет, Alt убирает). Для рамки и полигона критерий: «Пересекает контур» или «Полностью внутри».

## Структура репозитория

```
index.html           разметка интерфейса
style.css            оформление
app.js               данные, слои, показатели, экспорт, фильтры (исторически большой файл)
population-symbols.js / .css  отдельный интерактивный слой населения
map-runtime.js       отрисовка слоёв, подписи, события карты, движок выборки
selection-sketch.js  эскиз рамки и полигона (отдельный SVG-слой поверх карты)
atlas-geometry.js    независимые операции с полигонами GeoJSON
timeline-axis.js     непрерывная ось прокручиваемой шкалы лет
data/                GeoJSON и таблицы; data/manifest.json — перечень срезов
pipeline/            скрипты подготовки данных (запускать из корня репозитория)
scripts/             проверка структуры и административных GeoJSON
tests/               тесты логики выборки (node --test)
docs/                ARCHITECTURE.md, METHODS.md, CHANGELOG.md и отчёты расчётов
```

Для адаптации под другую территорию (например, Турцию) начните с [ARCHITECTURE.md](docs/ARCHITECTURE.md): там описаны поля GeoJSON, порядок загрузки и места с географическими допущениями. Скрипты `pipeline/recalc_v*.py` относятся к данным Западной Сибири и могут перезаписать файлы в `data/`.

Символы населения показывают сведения при наведении, подсвечиваются и позволяют выбрать соответствующую АТЕ кликом или клавишей Enter. При отсутствии числового населения в видимых АТЕ слой показывает пояснение. В исходных срезах 1700–1805 гг. положительных значений `population` нет. Клик по пустому месту карты снимает выборку и очищает карточку объекта в любом режиме. Для полигона такой клик с готовой выборкой только снимает выделение; следующий клик может начать новый контур. Шкала лет прокручивается; тонкая ось продолжается до последнего года. Фильтры АТЕ при запуске свёрнуты. Статистика слоя и выборки находится в правой панели, а исходные поля GeoJSON в карточке объекта можно раскрыть при необходимости. Кнопка экспорта в левой панели находится ниже легенды; плавающая кнопка остаётся ниже верхней статусной панели с отступом 12 px.

## Проверка изменений

```bash
node --test tests/*.test.js
python3 scripts/atlas_healthcheck.py
python3 scripts/validate_admin_geojson.py
```

Проверка текущих административных данных находит пять объектов без названия и административной принадлежности (1897, 1914 и 1926 гг.). Геометрия и идентификаторы проходят проверку. Для набора, где подписи обязательны, используйте `python3 scripts/validate_admin_geojson.py --strict-labels`.

Для отдельной проверки символов населения откройте `http://localhost:8000/tests/population-browser.html`. Стенд использует настоящий Leaflet, проверяет попадание курсора в круги и позволяет проверить наведение вручную.

## Данные и источники

Основные методические оговорки сведены в [METHODS.md](docs/METHODS.md), а история ключевых изменений в [CHANGELOG.md](docs/CHANGELOG.md). Подробные операции с данными доступны в диагностических CSV/JSON `docs/`, исходных расчётных скриптах и истории Git. Перед повторным использованием набора проверьте применимость конкретного временного среза: реконструкции не образуют однородный ряд современных АТЕ.
