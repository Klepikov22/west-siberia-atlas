# v146 — скрытие базового сломанного стиля ВШЭ

Исправление UI:
- из списка «Стиль районов» убран пункт `ВШЭ · защита ВКР` (`hseDefense`);
- из списка «Стиль подложки» убран пункт `ВШЭ · защита ВКР` (`hseDefense`);
- если в браузере раньше было сохранено старое значение `hseDefense`, оно автоматически переводится на рабочий `hseDefenseBlue`;
- красная и синяя версии оставлены как отдельные стили;
- версия проекта поднята до v146, cache-busting для `app.js` и `style.css` обновлён до `?v=146`.

Техническая причина:
- базовый старый стиль `hseDefense` давал слишком хрупкое отображение гидрографии и подписей в живой карте, поэтому он скрыт из пользовательского выбора, но не удалён из legacy-кода, чтобы не ломать старые зависимости.
